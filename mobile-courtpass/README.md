# CourtPass Mobile (Expo RN)

React Native (Expo) player-facing app for the CourtPass membership/program system.

**This is a completely independent Expo project.** It does NOT share code, config, or
dependencies with `mobile/` (the CourtPay staff/tablet app) or the root Next.js app.

---

## Quick Start

```bash
cd mobile-courtpass
npm install
npx expo start
```

Scan the QR code with Expo Go (iOS/Android) or press `i` / `a` for simulators.

---

## Architecture

- **Navigation:** React Navigation (native stack + bottom tabs)
- **State:** Zustand with SecureStore persistence for auth
- **API:** Adapter layer consuming CourtFlow REST APIs (player endpoints)
- **Auth:** Custom JWT flow — player token stored in SecureStore as `courtpass_player_token`

## App Flow

```
Splash → Login → Main Tabs
  ├── Home        — dashboard / upcoming sessions
  ├── Programs    — browse & enroll in CourtPass programs
  ├── My Pass     — active enrollments, session usage
  └── Profile     — account settings, notifications
```

## Environment

Set these in `mobile-courtpass/.env` (never import from repo root `.env` or `mobile/.env`):

```
EXPO_PUBLIC_API_BASE_URL=https://your-api-url-here.up.railway.app
EXPO_PUBLIC_SOCKET_URL=https://your-api-url-here.up.railway.app
```

Internal QA against a LAN server: set `EXPO_PUBLIC_ALLOW_PRIVATE_API_IN_RELEASE=true`
(never ship that to app stores).

## ⚠️  Firebase / Push Notifications — TODO before first build

**`google-services.json` and `GoogleService-Info.plist` are NOT yet present.**

Before push notifications can work:

1. Go to the **Firebase Console → Project `courtflow-de995`**.
2. Add a new **Android app** with package name `com.thecourtflow.courtpass`.
   - This is a **separate entry** from the existing `com.courtpay.app` app — do not reuse it.
3. Download the new `google-services.json` and place it at `mobile-courtpass/google-services.json`.
4. Add a new **iOS app** with bundle ID `com.thecourtflow.courtpass`.
5. Download the new `GoogleService-Info.plist` and place it at `mobile-courtpass/GoogleService-Info.plist`.
6. Add both files to `.gitignore` (they are already listed) or store them in a secure secrets manager.
7. Register FCM APNs key / certificate in the Firebase iOS app settings.
8. Add `@react-native-firebase/app` and `@react-native-firebase/messaging` to `package.json`
   and follow the CourtFlow FCM push-notifications rule (firebase-admin-credentials.mdc).

## Building

```bash
# Local Android (requires android/ generated by expo prebuild)
cd mobile-courtpass
npx expo prebuild --platform android   # generates android/ locally (gitignored)
npx expo run:android

# Local iOS
npx expo prebuild --platform ios       # generates ios/ locally (gitignored)
npx expo run:ios

# EAS Cloud Build (set up eas.json first)
npx eas build --platform android --profile production
```
